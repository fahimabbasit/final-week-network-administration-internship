Network Administration Internship — 2026

Overview

This repository contains the work completed during my 8-week Network Administration Internship at ITSimplera Solutions.

The internship focused on practical network administration and enterprise networking. Throughout the program, I worked on designing, configuring, securing, and troubleshooting different network environments using Cisco technologies, Cisco Packet Tracer, and GNS3.

The internship concluded with a large-scale enterprise network capstone that combined routing, switching, network security, VPNs, services, and troubleshooting into a single environment.

Weekly Projects

Week 01 — Network Administration Fundamentals

Introduction to basic networking concepts, network device configuration, IP addressing, and practical network administration tasks.

Week 02 — Switching and Subnetting

Worked with:

- VLAN configuration
- VTP
- Trunking
- Inter-VLAN communication
- CIDR and subnetting

Week 03 — Enterprise Multi-Protocol Routing

Configured and tested multiple routing technologies, including:

- Static Routing
- RIP v1
- RIP v2
- Multi-Area OSPF

The focus was on route exchange, connectivity, and routing protocol behavior.

Week 04 — Enterprise Network Security and Access Control

Implemented network security and access control mechanisms to secure devices and network traffic.

Week 05 — Enterprise Services Infrastructure

Configured and tested enterprise network services and server connectivity.

Week 06 — WAN Technologies and High Availability

Focused on WAN connectivity, redundancy, and high availability.

Key areas included:

- WAN links
- Redundant connectivity
- Primary and backup routing
- Floating static routes
- Loopback addressing

Week 07 — VPN, Firewall and Secure Access

Implemented multiple security technologies, including:

- IPsec VPN
- Zone-Based Firewall
- AAA
- SSH
- Device hardening

Week 08 — Enterprise Network Infrastructure, Security and Disaster Recovery Capstone

The final capstone combined the concepts covered throughout the internship into a large-scale enterprise network.

The environment included:

- Headquarters
- Multiple branch locations
- Data Center
- DMZ
- Internet Edge
- Simulated ISP
- Multiple routers and network segments

The project involved designing, configuring, securing, optimizing, and troubleshooting the complete infrastructure.

Troubleshooting Experience

One of the most valuable parts of this internship was troubleshooting.

Not every configuration worked on the first attempt. During the final project, I worked through issues involving:

- OSPF neighbor relationships
- Missing OSPF routes
- Route summarization
- STP and Root Guard behavior
- VLAN and SVI connectivity
- DHCP address assignment
- VPN routing and IPsec verification
- NAT configuration
- Toolbox IP addressing and HTTP connectivity
- Primary and backup routing paths

These issues helped me move beyond simply applying configurations and develop a better understanding of how network traffic, routing protocols, and enterprise services behave in practice.
